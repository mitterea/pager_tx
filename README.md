# pager_tx — POCSAG / FLEX 寻呼发射机

用 C 实现的寻呼机发信工具，通过 UHD 驱动 USRP（B210 等）直接发射 POCSAG 或
FLEX 信号，支持汉字寻呼机（UTF-8 输入自动转 GB2312 编码）。

FLEX 协议实现参照 multimon-ng 解码器源码（`demod_flex.c` / `bch.c`）逆向整理，
BCH(31,21) 编码表移植自 multimon-ng `bch.c`（public domain / unlicense）。

## 编译

```bash
sudo apt install libuhd-dev   # 无 UHD 时也能编译，但只能 -o 输出基带文件
make
```

## 用法

```bash
# POCSAG（默认协议）
./pager_tx -f 155.4e6 -r 1200 -a 123456 -m "你好,今晚八点老地方见"

# FLEX 1600/2FSK
./pager_tx -p flex -f 155.4e6 -r 1600 -a 123456 -m "你好FLEX测试"
```

### 参数

| 参数 | 说明 |
|---|---|
| `-p PROTO` | 协议：`pocsag`（默认）或 `flex` |
| `-f FREQ`  | 发射频率 Hz，如 `155400000` 或 `155.4e6`（必填） |
| `-r RATE`  | 速率：POCSAG `512/1200/2400`，FLEX 固定 `1600`（必填） |
| `-a RIC`   | 地址码/CAPCODE：POCSAG 0..2097151，FLEX 0..1933310（必填） |
| `-m MSG`   | 消息文本，UTF-8，中文自动转 GB2312（必填） |
| `-F FUNC`  | POCSAG 功能位 0-3，默认 3（字母数字/中文） |
| `-g GAIN`  | 发射增益 dB，默认 40 |
| `-s SRATE` | 基带采样率，默认 1000000 |
| `-n N`     | POCSAG：重复次数（默认 1）；FLEX：连续帧数（默认 16 帧 = 30 秒） |
| `-i`       | 反转 POCSAG 的 FSK 极性（收不到时试试） |
| `-o FILE`  | 不发射，把基带（fc32）写入文件，用于调试 |
| `-W`       | 关闭 ASCII 转全角（默认开启；纯英文寻呼机用） |
| `-A ARGS`  | UHD 设备参数，如 `"serial=xxxx"` |

## 工作原理

### 汉字编码

POCSAG/FLEX 的字母数字消息都是 7bit/字符。汉字按国内中文寻呼机的通行做法：
消息先转 GB2312，发送时每个字节剥掉最高位（0xA1..0xFE → 0x21..0x7E），
寻呼机收到后自行补回高位还原 GB 码显示汉字。

**注意**：这类寻呼机把所有落在 GB 区间的字节对都拼成汉字——半角 "11" 会被拼成
0xB1B1 = "北"。所以本程序默认把 ASCII 可打印字符转成 GB2312 全角（"1" → "１"），
与当年寻呼台的做法一致；给纯英文寻呼机发消息时用 `-W` 关闭。
消息中含 GB2312 无法表示的字符（emoji、生僻字等）时程序会警告并跳过。

### POCSAG

- 前导码（576bit 交替码）+ 若干批次，每批 = 同步字 0x7CD215D8 + 16 个码字；
- 码字为 BCH(31,21) + 偶校验；地址码放在 `RIC % 8` 对应的帧，长消息自动跨批；
- 2-FSK，频偏 ±4.5 kHz，默认逻辑 0 = 正频偏（`-i` 可反转）。

### FLEX

- 只实现 1600bps 2FSK（国内 FLEX 台最常用制式），短地址（capcode ≤ 1933310）；
- 帧结构（严格 1.875 s）：64bit 同步字 → 16bit 点频 → FIW（帧号/周期号/校验和）
  → 40bit 空位 → 88 个 32bit 码字（BCH(31,21,2) + 偶校验，8 块交织）；
- 消息 = BIW + 地址字 + 向量字 + 字母数字消息字，单帧最多 251 个 7bit 字符
  （约 125 个汉字），超长自动截断；
- cycle/frame 编号按当前 UTC 时间推算，逐帧递增连续发射；真 FLEX 寻呼机只在
  自己分配的帧醒来，本程序每帧都带消息，保证能撞上（若机器几个周期才醒一次，
  请加大 `-n`，如 `-n 256` 连发 8 分钟）。

## 验证

本仓库的信号已通过 multimon-ng（独立开源解码器）实测解码：

```
$ ./pager_tx -p flex -f 155.4e6 -r 1600 -a 123456 -m "你好FLEX测试ABC123" -o /tmp/flex.fc32 -s 22050
$ ./pager_tx -f 155.4e6 -r 1200 -a 123456 -m "你好ABC123" -o /tmp/poc.fc32 -s 22050
# 基带 FM 解调成音频后:
$ multimon-ng -a FLEX       -t raw /tmp/flex.s16
FLEX|1600/2/K/A|14.045|000123456|ALN|Dc:CFLEX2bJTABC123
$ multimon-ng -a POCSAG1200 -t raw /tmp/poc.s16
POCSAG1200: Address:  123456  Function: 3  Alpha:   Dc:CABC123<ETX>...
```

## 注意事项

- B210 输出功率很小（约 +10 dBm），实验时寻呼机放旁边即可；
- 全角模式下消息末尾用全角空格填充（显示为空白）；`-W` 模式按标准用 ETX 填充
  （个别寻呼机会把 ETX 显示成方块字符，无害）；
- 收不到时的排查顺序：POCSAG 加 `-i` → 加大 `-n` → 确认速率/地址码/频率无误
  → 换 `-F` 功能位；
- 个别中文机型的编码约定不同（如 GB 码不剥高位、功能位定义不同），需查该机型资料；
- **法律提示**：寻呼频段的发射需要无线电许可。实验请用同轴直连、屏蔽箱或
  极小功率近距离进行，不要接天线对空发射。
